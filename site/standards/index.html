The proof of concept

53 standards

Every Common Core math standard for sixth and seventh grade, and whether we have a worked problem for it that passed every gate. When this board is green, the machine is proven — and higher grades are the same machine with harder inputs.

How to read this

What “done” means here

A standard is only marked done when there is a problem that:

  • teaches on the page before it asks anything — the answer is findable in what the child just read, not in a memory of last year;
  • has a figure, where it needs one, that was drawn from the same numbers as the answer and then measured back to prove it matches;
  • has an answer the machine computed, cross-checked a second independent way, with the units and the domain right;
  • passed every gate — nothing overflowing the page, no labels printed on top of each other, no text cropped off a figure, every font real;
  • carries the standard code honestly — the child does what the standard actually describes, at the grade it is written for, or the code is absent and the reason is written down.
Where these codes come from

Nobody typed these

All 53 come out of a frozen table of the 664 official Common Core math codes, pulled from the machine-readable release and checked into the repo with a date stamp. A code that isn’t in that table cannot appear on this board or on a product.

That matters more than it sounds like it should. The official website’s per-standard pages now return “not found,” the official PDF doesn’t contain the codes at all, and the site that looks official answers 200 OK for made-up codes — so anything that checks a code by loading its web page would wave through every typo it was ever handed.

The trap worth knowing

There are two official machine-readable releases of these codes and they disagree on 124 of the 664. The wrong one is the file published by the standards body itself. Build off it and every fine-grained code — exactly the kind a math worksheet cites most — comes out malformed, and nothing tells you.

We’re on the correct one, and the generator asserts it every time it runs.
